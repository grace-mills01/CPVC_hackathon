# ToGo

ToGo helps people connect through sports, coordinate games, and recharge together. We're starting with the Cal Poly community.

This repository currently contains a React/Vite foundation, proposed domain shapes, and a database outline. Game features and database connectivity are not implemented yet. See [PROJECT_PLAN.md](PROJECT_PLAN.md) for the design and workflow.

## Development

Install Node.js 22 and run `npm ci`, then `npm run dev`. Run `npm test` and `npm run build` to verify changes. Copy `.env.example` to `.env` when a Supabase project is configured; never commit secrets.
